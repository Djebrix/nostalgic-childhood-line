One single sentence recalling a childhood memory, written for the
[Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363)
bounty on make.fun.

## Entry

> Grandma's kitchen smelled of fresh rice and woodsmoke, and the radio crackled the same song every evening while she saved me the crisped corner of the pan.

## How it works

`main.py` (Python standard library only) writes the sentence above to
`/output/entry.txt`. The output is deterministic: every run produces the
exact same bytes.

Run it:

```sh
python3 main.py
```
